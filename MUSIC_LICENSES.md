# Audio & Music Attribution

This project uses third-party audio assets for background music, ambient sounds, and interface effects.

## Lofi Tracks

All fourteen lofi tracks ship in the app from [Pixabay](https://pixabay.com/music/) under the [Pixabay Content License](https://pixabay.com/service/license-summary/). Each file in `assets/audio/lofi/` is named `Title - Author.mp3`.

**Author vs. contributor.** The track page shows only the contributor's Pixabay handle. The name in the Author column is the one on that contributor's *profile* details block, which the track page does not display — check it by opening the handle's profile, not the track. Where a profile carries no separate name the handle stands in for both, which is why two contributors each have a track called just "Lofi".

## Sound Effects (SFX)

Both effects are sourced from [Freesound](https://freesound.org), and both are **CC0 1.0**, so neither needs attribution and neither restricts commercial use.

| Effect            | File                  | Used for                    | Author     | Source                                    | Licence |
| :---------------- | :-------------------- | :-------------------------- | :--------- | :---------------------------------------- | :------ |
| Chime             | `chime.mp3`           | Session-end notification    | drooler    | [660863](https://freesound.org/s/660863/) | CC0 1.0 |
| Session End Chime | `SessionEndChime.MP3` | In-app chime at session end | AnthonyRox | [740423](https://freesound.org/s/740423/) | CC0 1.0 |

**File names are deliberate, including their casing.** `chime.mp3` is lower case because Android notification resources require it; `SessionEndChime.MP3` keeps the capital `.MP3`. `components/music-tracks.ts`, `components/wickglow/domain/notifications.ts` and the `expo-notifications` `sounds` entry in `app.json` each reference these exact names, and a case mismatch fails the bundle. Both files are real MP3s (ID3 v2.4).

**Status.** All bundled audio is now covered: no file needs a purchase, and none needs a credits screen.
