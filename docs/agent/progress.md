## Next up

Interim (owner request, 2026-11-12): a sideloaded APK from the `preview` profile (`eas build --platform android --profile preview`; `eas.json` sets `buildType: apk` and `autoIncrement`). It uses the same EAS keystore that Play will use later, so do not delete that keystore. EAS builds pin Node 24.12.0 (`eas.json` `base` profile), and `package-lock.json` is made with normal peer dependency handling (it was rebuilt on 2026-11-13 because a user-level `legacy-peer-deps=true` had left out six peers). If your own npm config has `legacy-peer-deps=true`, turn it off (`npm config delete legacy-peer-deps`), or `npm ci` on EAS fails with "lock file out of sync". The EAS project is `@cent_1214/wickglow` (the old project id was not found and was replaced on 2026-11-13).
